# LAB Character System

Status: exploratory brand support system.

This file captures the working direction for the illustrated guide character currently referred to internally as **CEO Millennial Uncle**.

---

## Role In The Brand

CEO Millennial Uncle is the approachable founder/operator guide character.

Not:

- genius in a lab coat
- corporate CEO
- literal staff member
- mascot-as-proof

More like:

> I know the systems are messy. Sit down, have a coffee, we'll make this useful.

---

## Why It Works

| Visual cue | Meaning |
|---|---|
| Hoodie + mug | relaxed, accessible, not corporate |
| Laptop + plant | builder/operator energy |
| Small robot | friendly AI, not threatening AI |
| Glasses + soft expression | thoughtful, safe, competent |
| Warm illustration style | humanises technical work |

---

## Strategic Role

The character is not the evidence.

The character is the narrator.

A mascot attracts attention.

A narrator reduces confusion.

LAB needs confusion reduction.

---

## Best Use Cases

Use the guide character for:

- onboarding sections
- explainers
- what-happens-next panels
- friendly warnings
- website help bubbles
- AI assistant mascot moments
- LAB Notes or Field Notes visuals
- contact-page reassurance

---

## Avoid Use Cases

Do not use the guide character as:

- the homepage hero
- the company logo
- the Safe Intake proof itself
- the primary trust signal
- literal staff photography
- proof of capability

---

## Public Framing

Prefer public framing like:

> LAB Character System
>
> A set of illustrated guides used to explain different parts of AI, workflow, evidence, and creative systems.

Avoid presenting the character as literal staff unless intentionally fictional and clearly labelled.

---

## Design Boundary

The guide character may explain the system.

The guide character may never become the evidence for the system.

Evidence remains:

- Safe Intake Proof 001
- workflow states
- approval gates
- audit events
- traceability

The character helps visitors understand those things.

---

## System + Guide Pattern

```text
Symbol
= system

Guide character
= human interpretation

System + Guide
= approachable competence
```

The symbol says:

> There is a system.

The character says:

> You can understand it.

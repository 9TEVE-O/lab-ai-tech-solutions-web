# Sprint Control - LAB AI & Tech Solutions

## Mission

Expand the existing proof-of-concept into a public operating hub.

## Current Priority

Create the repo-controlled website shell with Demo, Evidence, Roadmap, and Access pillars.

## Definition of Done

- GitHub repo is the source of truth.
- Website shell builds from the repo.
- Home page explains the project clearly.
- Demo pathway is visible.
- Evidence layer is visible.
- Roadmap is visible.
- Access CTA is visible.
- Mobile layout is usable.

## Do Not Build Yet

- Auth
- Payments
- Client dashboards
- Feeds
- Comments
- Complex backend
- Multi-user workflows

## Operating Rule

If it matters, it goes in the repo. If it changes direction, it goes in the decision log. If it proves progress, it goes in the evidence log.

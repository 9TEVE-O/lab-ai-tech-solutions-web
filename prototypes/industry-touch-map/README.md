# LAB Industry Touch Map — Responsive Prototype

**Status:** Internal responsive prototype / evidence-bound strategic interface  
**Snapshot:** 18 July 2026  
**Route status:** Standalone prototype only. It is not merged into the LAB website application or approved as a public page.

## Purpose

This prototype converts the wide 20-sector opportunity table into a mobile-first information flow:

1. decision and authority boundary;
2. summary metrics and distribution charts;
3. five public-positioning domains;
4. searchable and filterable sector cards;
5. optional desktop comparison matrix;
6. state definitions, claim controls and review rules.

## Files

- `index.html` — semantic page structure
- `styles.css` — responsive layout and component styling
- `app.js` — sector data, filtering, search and view switching
- `../../docs/01_STRATEGY/LAB_INDUSTRY_TOUCH_MAP_90D_2026-07-18.md` — authority source
- `../../docs/04_IMPLEMENTATION/LAB_INDUSTRY_TOUCH_MAP_RESPONSIVE_UI_NOTES_2026-07-18.md` — redesign rationale

## Review gate

Open the prototype on a phone and assess the information order before changing colours, branding or component styling.

Review specifically:

- whether the decision and authority boundary appear early enough;
- whether the charts help orientation or delay the useful content;
- whether the five-domain layer should precede the sector explorer;
- whether collapsed evidence details provide enough context;
- whether claim controls appear at the correct point in the journey; and
- whether the final state-change rule produces a clear next decision.

## Boundary

The interface changes presentation only. It does not alter evidence states, lifecycle states, opportunity posture, public-safe wording or authority boundaries.
